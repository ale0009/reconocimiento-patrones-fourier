# Política de Seguridad / Security Policy

## Versiones soportadas

Las siguientes versiones cuentan actualmente con actualizaciones y parches de seguridad:

| Versión | Soportada |
| --- | --- |
| 0.1.0 | Sí |
| < 0.1.0 | No |

## Reporte de vulnerabilidades

La seguridad de este proyecto se toma con seriedad. Si identificas una vulnerabilidad de seguridad, agradecemos que la comuniques de manera responsable antes de hacerla pública.

### Cómo reportar

Por favor, abre un aviso privado de seguridad en GitHub (Security → Report a vulnerability).

### Plazos de respuesta

- Acuse de recibo inicial: dentro de las primeras 48 horas posteriores al reporte.
- Evaluación técnica y confirmación de impacto: en un plazo no mayor a 7 días hábiles.
- Publicación de mitigación o parche: según la severidad y complejidad del hallazgo.

### Alcance

- Aplica a código fuente, scripts de despliegue y dependencias directas en la rama principal.
- Quedan excluidos ataques de denegación de servicio contra infraestructura externa, técnicas de ingeniería social y entornos no mantenidos.

---

## English Summary

Security issues are handled responsibly:
- Supported version: `0.1.0`.
- To report a vulnerability: please open a private security advisory on GitHub (Security → Report a vulnerability).
- Initial response within 48 hours; assessment within 7 business days.
- In-scope: source code, configuration and direct dependencies on the primary branch.
